## Boundary disclaimer (certification-body standard)

This is a **certification-body competence** standard. It specifies **additional requirements to ISO/IEC 17021-1** for bodies that audit and certify an Artificial Intelligence Management System (AIMS) according to ISO/IEC 42001. It is **not** an AIMS control set for HUMMBL, not a product certificate, and not a substitute for ISO/IEC 42001.

Official abstract (IEC/ISO): the requirements, when implemented, support competence, consistency and reliability of bodies performing AIMS audit and certification; certification of AIMS is a third-party conformity assessment activity (ISO/IEC 17000:2020, 4.5); the document can be used as a criteria document for accreditation or peer assessment.

HUMMBL is **not** a certification body, **not** an accreditation body, and **not** an AIMS. HUMMBL is an in-process library. The AIMS is the customer's. **Almost every row is Boundary.** This file exists so ISO 42006 is **not silent** in the coverage folder.

**Do not invent ISO 42004.** No public ISO/IEC 42004 standard was found this session. **Do not collapse this file with** [`iso-42001.md`](./iso-42001.md) (AIMS requirements) or [`iso-iec-42005.md`](./iso-iec-42005.md) (AI system impact assessment guidance).

**No public “fulfills ISO 42006.”** HUMMBL cannot fulfill a standard addressed to audit/certification bodies.
