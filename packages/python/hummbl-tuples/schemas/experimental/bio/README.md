# Bio-Governance Example Fixtures

This directory contains compact fixtures for bio-cognitive and bio-governance workflows.

These examples show a minimal path:

- signal capture
- workload and strain inference
- readiness inference
- adaptation proposal
- authorization
- execution
- blocked and override cases
- harm signaling
- observed outcome

The examples are intentionally simple. They are reference cases for schema validation and early workflow design, not claims about clinical or coaching-grade validity.
