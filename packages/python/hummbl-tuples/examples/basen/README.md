# BaseN Example Fixtures

This directory contains compact reasoning-path fixtures for four control regimes:

- `ai_autonomous`
- `ai_propose_human_confirm`
- `hitl_influenced`
- `hitl_controlled`

These examples are not benchmark results. They are schema-legible reference cases showing how the tuple taxonomy can encode:

- transformation choice
- mental model choice
- overrides
- reasoning paths
- path comparison
- evidence
