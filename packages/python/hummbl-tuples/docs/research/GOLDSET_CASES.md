# Goldset Cases

Status: draft

## Purpose

Track candidate benchmark cases for calibration, scoring, and comparative experiments.

## Candidate Sets

### Wickedness / Tiering

- flat tire
- CRM implementation
- organizational culture change
- climate change mitigation

### BaseN / Reasoning Path

- research synthesis task
- debugging task
- strategic planning task
- evaluation-design task

### Readiness / BKI

- high-trust small-team execution case
- low-capacity coordination case
- high-contestation but strong coordination case
- low-contestation but low-readiness case

### Bio-Cognitive / Bio-Governance

- low-fatigue research block
- moderate-fatigue long writing block
- overload during coordination session
- weak-signal false positive
- adaptation harms flow
- high-strain signal with insufficient evidence

## What Each Case Should Eventually Include

- canonical description
- intended layer or framework
- expected score/profile
- manual scoring notes
- model or classifier outputs
- comparison outcomes
