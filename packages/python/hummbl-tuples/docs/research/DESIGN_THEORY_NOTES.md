# Design Theory Notes

Date: 2026-03-27
Status: draft

## Question

What does design theory add to HUMMBL?

## Bottom Line

Design theory gives HUMMBL a disciplined way to handle framing, iteration, and wicked problems. It is the clearest domain for saying that problem definition and solution generation co-evolve, and that good systems need reflective cycles rather than one-shot optimization.

For HUMMBL, this matters because Base120/BaseN should not only generate answers. They should help reframe problems, surface alternatives, and support iterative movement through ambiguity.

## Core Ideas

- wicked problems do not admit neat, final solutions
- framing is part of solving, not something completed in advance
- reflective practice matters because designers learn by interacting with situations
- prototypes and intermediate artifacts are thinking tools, not only outputs
- iteration should be expected, not treated as failure

## What HUMMBL Should Borrow

- treat framing and reframing as first-class reasoning actions
- use intermediate artifacts and tuples as thinking tools
- support iteration rather than premature closure
- distinguish solution search from problem structuring
- make reflective loops visible to operators

## What HUMMBL Should Avoid

- pretending every problem is well-structured
- treating the first successful answer as the final one
- collapsing design exploration into linear execution
- overclaiming precision where ambiguity is intrinsic
- using elegant abstractions to suppress disagreement or uncertainty

## Relation To HUMMBL

- Base120 / BaseN  
  Strong fit as a repertoire for reframing, decomposition, and iterative reasoning.
- tuples / governance  
  Tuples can encode reframes, alternatives, prototypes, and reflective checkpoints.
- world models / reasoning traces  
  Design theory helps distinguish exploratory reasoning from predictive modeling.
- readiness / BKI  
  Strong fit because readiness depends on whether people can work productively with ambiguity rather than merely execute fixed plans.

## Confidence

High on relevance; medium-high on the HUMMBL synthesis.
