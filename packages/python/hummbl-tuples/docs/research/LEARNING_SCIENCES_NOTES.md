# Learning Sciences Notes

# Date: 2026-03-27
Status: draft

## Question

What do learning sciences add to HUMMBL?

## Bottom Line

Learning sciences give HUMMBL the scaffolding, metacognition, feedback, and transfer vocabulary it needs to help humans and agents actually improve over time. It is the right lens when the question is not just whether a system can answer, but whether it can teach, support self-regulation, and transfer skill across contexts.

For HUMMBL, the lesson is that Base120/BaseN should be usable as a learning scaffold, not only as a reasoning taxonomy. Tuples should also preserve the history of learning, correction, and transfer.

## Core Ideas

- learning is strengthened by prior knowledge and conceptual frameworks
- scaffolding should support independent performance over time
- metacognition and self-regulation are central to durable learning
- feedback is necessary for calibration and improvement
- transfer is a core criterion of meaningful learning

## What HUMMBL Should Borrow

- use scaffolding to reduce cognitive load while building independence
- build explicit metacognitive prompts into reasoning workflows
- make feedback fast, specific, and tied to goals
- test transfer across contexts, not only performance on the training case
- support progressive release of responsibility from system to user

## What HUMMBL Should Avoid

- assuming exposure or output equals learning
- over-scaffolding so the user never internalizes the skill
- treating feedback as blame rather than calibration
- confusing surface memorization with durable transfer
- building learning supports that are disconnected from the actual workflow

## Relation To HUMMBL

- Base120 / BaseN  
  Strong fit as scaffolds for reasoning, reflection, and independent problem solving.
- tuples / governance  
  Strong fit for recording attempts, feedback, corrections, and transfer evidence.
- world models / reasoning traces  
  Learning sciences helps HUMMBL evaluate whether traces support learning or merely log outputs.
- readiness / BKI  
  Very strong fit. Readiness depends on whether humans can learn the system and the system can support human learning.
