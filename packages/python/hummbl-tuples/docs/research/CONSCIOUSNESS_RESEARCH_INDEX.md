# Consciousness Research Index

Status: draft

## Purpose

Track which consciousness-adjacent ideas are useful to HUMMBL and which are not.

## Working Buckets

- `global-workspace`
- `higher-order`
- `self-model`
- `metacognition`
- `subjective-experience-caution`

## Notes

- `global workspace` is the most operationally useful concept for HUMMBL.
- `higher-order` is useful for self-monitoring and reflection layers.
- `self-model` is useful for architecture, but not as a consciousness claim.
- `metacognition` is useful for confidence, self-evaluation, and error monitoring.
- `subjective experience` claims should be treated as unsupported unless the evidence is much stronger than current model self-reports.
