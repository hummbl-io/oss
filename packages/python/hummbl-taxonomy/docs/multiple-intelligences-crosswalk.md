# Multiple Intelligences Crosswalk

**Status:** Draft v0.1  
**Last Updated:** 2026-04-20

## Purpose

This document explores productive comparisons between human multiple-intelligences theory and artificial intelligence tiers in the HUMMBL taxonomy.

It is an analytical crosswalk, not a claim that human and artificial cognition are identical.

## Framing

Human multiple-intelligences theory can help in two ways:

1. identify which kinds of competence an artificial system really possesses,
2. avoid treating all “intelligence” as one undifferentiated scalar.

This is useful when distinguishing ANI, ASPI, AGI, and ASI.

## Human Intelligence Modes

The common working set includes:

- linguistic
- logical-mathematical
- spatial
- bodily-kinesthetic
- musical
- interpersonal
- intrapersonal
- naturalistic

## Artificial Comparison Logic

Artificial systems should not be mapped one-to-one onto human intelligences.

But the framework is still useful for asking:

- which competence modes are present,
- how integrated they are,
- whether integration is domain-bounded or general,
- whether governance assumptions should change as more modes integrate.

## Working Crosswalk

| Human Intelligence Mode | Artificial Analogue |
| --- | --- |
| linguistic | language modeling, dialogue, writing, semantic transformation |
| logical-mathematical | formal reasoning, proofs, planning, optimization |
| spatial | vision, scene reasoning, simulation, robotics perception |
| bodily-kinesthetic | physical control, robotics, embodied actuation |
| musical | temporal sequence modeling, pattern-sensitive generative systems |
| interpersonal | negotiation, coordination, theory-of-mind-like social modeling |
| intrapersonal | self-monitoring, self-modeling, reflective governance, introspective diagnostics |
| naturalistic | classification, environmental modeling, ecological pattern recognition |

## How This Helps HUMMBL Tiers

### ANI

ANI often occupies one narrow slice of one intelligence mode.

Examples:

- a classifier,
- a translator,
- a detector,
- a narrow planner.

### ASPI

ASPI often integrates several intelligence modes, but within one coherent domain.

Examples:

- a governed coding agent combines linguistic, logical-mathematical, and intrapersonal-like self-monitoring abilities within software engineering
- a research agent combines linguistic, logical, and limited interpersonal coordination within research workflows

### AGI

AGI would require broad integration across many intelligence modes in a way that is not bounded by one domain family.

### ASI

ASI would imply superhuman integration and coordination across the full set and beyond human baselines.

## Useful Cautions

This crosswalk should not be abused in the following ways:

- do not anthropomorphize systems just because they show competence in one mode,
- do not confuse benchmark skill with general intelligence,
- do not assume “more modes” automatically means AGI,
- do not import educational psychology claims uncritically into technical governance.

## Productive Use

The crosswalk is most useful for:

- capability decomposition,
- taxonomy refinement,
- evaluation design,
- governance trigger design,
- explaining why ASPI is a real middle tier rather than a rhetorical convenience.

## Core Claim

Multiple-intelligences theory is useful for HUMMBL not because it proves AGI, but because it helps decompose what kinds of competence are actually present and how tightly integrated they are.
