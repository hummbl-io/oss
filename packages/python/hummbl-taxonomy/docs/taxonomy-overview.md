# HUMMBL Taxonomy Overview

**Status:** Draft v0.1  
**Last Updated:** 2026-04-20

## Purpose

This document gives the canonical overview of the HUMMBL intelligence taxonomy.

## Four Tiers

| Tier | Scope | Governance Posture |
| --- | --- | --- |
| `ANI` | one task or narrow workflow | deterministic control |
| `ASPI` | one coherent domain or task class | autonomy-with-guardrails |
| `AGI` | arbitrary domains | containment-first |
| `ASI` | beyond human across domains | theoretical containment |

## Transition Mechanism

The taxonomy is dynamic rather than static.

The main transition mechanism is RSI:

- `ANI -> ASPI`: narrow systems accumulate domain breadth and bounded autonomy
- `ASPI -> AGI`: domain-bounded systems begin to generalize across unrelated domains
- `AGI -> ASI`: full recursive self-improvement creates superhuman broad capability

## Repo Map

- `hummbl-ani` defines the narrow baseline
- `hummbl-aspi` defines the main deployment tier
- `hummbl-agi` defines the transition to domain-general intelligence
- `hummbl-asi` defines the superintelligence boundary
- `hummbl-rsi` defines the compounding mechanism

## Core Claim

The HUMMBL taxonomy is useful only if each tier changes governance assumptions, not just vocabulary.
