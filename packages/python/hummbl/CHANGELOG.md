## [0.1.0] - 2026-08-22

### Added
- Initial PyPI release of the hummbl package
- Reasoning primitives (`reasoning.py`) — plans, hypotheses, observations, evaluations, decisions, reflections
- Scientific method and quality assessment protocols (`protocols.py`)
- Planning primitives (`planner.py`)
- Capture from existing artifacts or live runtime hooks (`capture.py`)
- Local analysis of reasoning traces (`analyzer.py`)
- Scoring reasoning artifacts (`scoring.py`)
- Visualization of reasoning traces (`visualize.py`)
- Command-line interface (`cli.py`)
- Zero runtime dependencies (stdlib-only)
- Apache-2.0 license
