## Findings

### P2 — 12 deprecated `datetime.utcnow()` calls
Two crosswalk scripts use `datetime.datetime.utcnow()` which is deprecated in Python 3.12+:
- `scripts/arcana_praxis_poiesis_crosswalk.py`: lines 123, 132, 520, 559, 582, 586
- `scripts/prawn_arcana_praxis_crosswalk.py`: lines 105, 114, 442, 479, 505, 509

Ruff flags these as `DTZ003`. Replace with `datetime.now(UTC)` (using `from datetime import UTC`).

### P2 — Quickstart documentation is stale
`docs/quickstart.md` has two accuracy issues:
1. Line 8 states "Python 3.10+" but `pyproject.toml` line 11 specifies `requires-python = ">=3.11"`.
2. Lines 136-141 state "64 tests total" and list only 3 test files, but `pytest --collect-only` collects 225 tests across 12 test files. The test count and file list are significantly out of date.

### P2 — 11 MEDIUM bandit B310 findings (urlopen permitted schemes)
Multiple files use `urllib.request.urlopen()` without restricting URL schemes:
- `ollama_client.py:26`, `pipeline/ollama_client.py:33`
- `scripts/_gen_common.py:187`
- `scripts/arcana_praxis_poiesis_crosswalk.py:233, 280, 498`
- `scripts/overnight_v0.py:97`
- `scripts/prawn_arcana_praxis_crosswalk.py:205, 244, 420`
- `sources/supadata_source.py:59`

These connect to Ollama endpoints and external APIs. While the URLs are constructed from config, restricting allowed schemes to `http`/`https` would prevent file:// or custom scheme injection.

### P3 — 4 MEDIUM bandit B108 findings (insecure temp files)
- `scripts/arcana_praxis_poiesis_crosswalk.py:45, 46` — two insecure temp file/directory usages
- `scripts/prawn_arcana_praxis_crosswalk.py:66, 67` — two insecure temp file/directory usages

## Recommendations

1. Replace all 12 `datetime.utcnow()` calls with `datetime.now(UTC)` in `scripts/arcana_praxis_poiesis_crosswalk.py` and `scripts/prawn_arcana_praxis_crosswalk.py`.
2. Update `docs/quickstart.md` — change "Python 3.10+" to "Python 3.11+" and update the test count from "64 tests" to the current 225 tests across 12 files.
3. Run `ruff check . --fix` to auto-fix the 185 lint findings (unused noqa, unused imports, f-string cleanup, regex alias expansion).
4. Pin the dev dependency `pytest>=9.1.1` with an upper bound (e.g., `<10.0`).
5. Consider restricting URL schemes in `urlopen` calls across the 11 B310 findings to `http` and `https` only.
