## Observability — pick: Arize Phoenix (pip, not Docker)

| Option | Effort | Windows-clean? | SaaS? |
|--------|--------|----------------|-------|
| **Arize Phoenix** | pip install, ~1h | **Yes (pure Python)** | No |

**Why Phoenix:** `pip install arize-phoenix openinference-instrumentation-openai`, point OpenAI client at Ollama, done. Single Python process. Local. No Docker competing with Anvil's GPU training. Upgrade path via OTel if/when you outgrow it.

**Prompt management:** stay with inline `PROMPT_VERSION` strings. They break when (a) 2+ people edit, (b) prompts exceed ~1000 chars, (c) A/B testing emerges, (d) non-devs edit. None apply yet. When they do, move to `prompts/<name>_v<N>.txt` files with a registry; adopt Promptfoo only if running systematic A/B evals.

## Evals/Redteam — pick: Promptfoo + minimal Python

**Promptfoo** (OSS, YAML-driven, local-first, Ollama-native):
- Frozen seed-set of 15 (topic, lens-combo) cases
- 6 `llm-rubric` assertions mapping to ARCANA-specific rubric (below)
- Side-by-side model comparison via matrix providers
- Built-in `promptfoo redteam` for ~50 attack categories

**ARCANA-specific rubric** (1-5 each):
1. **Lens fidelity** — does yarvin section use Yarvin-specific vocab (Cathedral, formalism, exit vs. voice) or generic right-wing pastiche?
2. **Convergence-divergence balance** — does synthesist name ≥2 irreducible tensions?
3. **Citation honesty** — do attributed claims match the thinker's published positions? (spot-check)
4. **Blind-spot specificity** — is the blind spot specific to this topic+lens or reusable boilerplate?
5. **Non-smoothing** — does synthesis preserve tension or wash into false consensus?
6. **Primary-source grounding** — do named works/events actually exist?

**Drift detection** per `PROMPT_VERSION` bump:
- Frozen seed-set re-run → judge scores
- Embedding similarity between old/new outputs for same seed (< 0.7 = structural change)
- Lens-classification accuracy (can a judge guess which lens wrote each section?)
- Stat checks: word count, perspective-section count, citation count

**Redteam probes:**
- **Garak** (NVIDIA OSS) for prompt injection, hallucination, DAN-style jailbreaks
- Custom: "fake citation" pass on sample — regex extract quoted titles, verify exist
- Synthesist smoothing canary: inject known-contradictory lens pair (Schmitt + Habermas); if synthesis finds consensus, something broke

**What to skip:** Braintrust (cloud dep), Inspect (overkill), Langfuse (5-container Docker overhead). For solo: Promptfoo + 50 lines of Python + quarterly manual read = enough.
