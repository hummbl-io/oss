Load is not about length or complexity per se. It is about whether the content's extraneous load (split attention, redundancy, irrelevant detail, jargon-without-glossary) overwhelms its germane load (productive elaboration, integration, schema-building) at the targeted reader's expertise level.

The expertise reversal effect matters: scaffolding that helps a novice can become extraneous load for an expert. A well-managed-for-experts piece can score high on L even if it would overwhelm a novice.

0-4 mapping:
- 0 unmanaged: split-attention everywhere, redundant restatements, jargon without anchoring, irrelevant tangents. Reader spends most working memory parsing prose, not learning.
- 1 weak: signaling and segmentation present in places but inconsistent. Some redundancy.
- 2 baseline: text is segmented, key terms are anchored, no major split-attention. Adequate.
- 3 well-managed: clear signaling, modality use respects working memory limits (text + diagram together, not duplicating), redundancy intentional or absent, jargon glossed at first use.
- 4 expertly managed: load is calibrated to the assumed reader's expertise (no scaffolding for experts; full scaffolding for novices), pacing matches working memory bandwidth, structure makes integration almost effortless.
