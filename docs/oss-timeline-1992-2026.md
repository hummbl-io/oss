# Open Source Timeline

**16 March 1992 – 30 August 2026**

A curated map of the events that changed free and open-source software, anchored to 16 March 1992 — the day before two free Unixes became real on cheap PCs.

This is a *key-event* timeline, not a complete catalog. By the mid-2000s that catalog is already impossible. Exact days are given when they are well attested; otherwise month or year.

Until 1998 the field is still called **free software**. The phrase **open source** does not exist yet.

## How to read this

- **Bold dates** are load-bearing.
- Projects, licenses, lawsuits, IPOs, and forks are included when they changed how the field worked — not merely when a version shipped.
- Predecessor context (GNU 1983, GPL 1989, Linux announced 25 August 1991, Linux 0.01 on 17 September 1991) sits *before* this window and is mentioned only when needed.

## 1992–1994 — Free Unix on a PC

The week the window opens.

| Date | Event |
|------|--------|
| **16 Mar 1992** | Timeline start. Linux 0.95 is nine days old and can run the X Window System. |
| **17 Mar 1992** | Linux **0.95a** (bug-fix of 0.95). **386BSD 0.0** ships — first fully operational free BSD Unix for Intel 386 PCs, by William and Lynne Jolitz. |
| Feb 1992 | **MCC Interim Linux** (Owen Le Blanc, University of Manchester) — first real Linux *distribution* with an installer, not just two floppy images. |
| Apr 1992 | Python 0.9.6. |
| **20 Apr 1992** | AT&T **Unix System Laboratories sues BSDI** over Unix intellectual property. The University of California is later added. The suit hangs over BSD for two years. |
| 1992 | Andrew Tridgell starts **Samba**. Usenet vote creates **`comp.os.linux`** (results 25 Mar; 858–5). |
| Jan 1992 | Linux 0.12 is relicensed under **GPLv2**. Andrew Tanenbaum posts **“LINUX is obsolete”** (29 Jan) — the Tanenbaum–Torvalds microkernel debate. |
| Mar 1993 | **NetBSD** begins, from frustration with 386BSD’s pace. |
| **17 Jul 1993** | **Slackware** (Patrick Volkerding) — oldest distro still maintained. |
| **16 Aug 1993** | Ian Murdock founds **Debian**. |
| Late 1993 | **FreeBSD** project begins (1.0 ships November). NCSA **Mosaic** popularizes the web. |
| Feb 1994 | USL/BSDI lawsuit **settles**. Path clears for **4.4BSD-Lite**. |
| **26 Jan 1994** | **Python 1.0**. |
| **14 Mar 1994** | **Linux 1.0** — first production kernel (~176k lines). |
| 1994 | First **Red Hat Linux**. Netscape Navigator. |

Linux is no longer a hobby posting. The BSD family is legally free. Distros exist.

## 1995–1997 — The web stack and the desktop

| Date | Event |
|------|--------|
| **1995** | **Apache HTTP Server** grows out of NCSA httpd (Apache Group). **PHP** (Rasmus Lerdorf). **Ruby** (Yukihiro Matsumoto). **GIMP**. **MySQL**. |
| **9 Jun 1996** | **Linux 2.0** — SMP. Larry Ewing draws **Tux**. |
| 1996 | **KDE** founded (Matthias Ettrich). StarOffice appears on Linux. |
| **May 1997** | Eric S. Raymond publishes **The Cathedral and the Bazaar**. |
| Aug 1997 | **GNOME** starts (Miguel de Icaza, Federico Mena) as a fully free desktop against Qt-licensed KDE. |

LAMP is assembling: Linux + Apache + MySQL + PHP/Perl. The internet’s default engine will be free software. Most of the business world has not noticed yet.

## 1998–2001 — The name “open source,” and money

The rebrand and the first IPO wave.

| Date | Event |
|------|--------|
| Jan 1998 | Netscape announces it will release Communicator source. |
| **3–8 Feb 1998** | Christine Peterson coins **“open source.”** **Open Source Initiative** founded (Eric S. Raymond and Bruce Perens). The Open Source Definition is adapted from the Debian Free Software Guidelines. |
| **31 Mar 1998** | **Mozilla** source drops. |
| Oct 1998 | Microsoft **Halloween Documents** leak — internal admission that OSS is a strategic threat. IBM, Oracle, and others start backing Linux. |
| 1999 | **Apache Software Foundation**. **GNOME 1.0**. Linux 2.2. SourceForge. First LinuxWorld. |
| **11 Aug 1999** | **Red Hat IPO**. |
| **9 Dec 1999** | **VA Linux IPO** — among the largest first-day pops in Wall Street history at the time. |
| **2000** | IBM commits **$1 billion** to Linux. **Python 2.0**. Sun opens StarOffice as **OpenOffice.org**. Dot-com peak, then crash. |
| 2001 | Linux **2.4**. Apple **Mac OS X** (Darwin kernel is OSS). Microsoft “Shared Source.” Wikipedia launches. First Kernel Summit. |

The *term* OSS is born. Linux becomes a company strategy, then a stock ticker, then (briefly) a bubble.

## 2002–2007 — Lawyers, browsers, and a new kernel culture

| Date | Event |
|------|--------|
| 2002 | Linus adopts **BitKeeper** for kernel development. **Mozilla 1.0**. **Creative Commons**. Apache 2.0. |
| **Mar 2003** | **SCO sues IBM**, claiming Unix code in Linux. Years of FUD; SCO later collapses. |
| 2003 | Linux **2.6**. **WordPress**. Phoenix → **Firefox**. **Fedora**. |
| **20 Oct 2004** | **Ubuntu 4.10 “Warty Warthog.”** |
| **9 Nov 2004** | **Firefox 1.0** — first mass-market OSS browser win against Internet Explorer. |
| **3–7 Apr 2005** | BitKeeper license yanked after a reverse-engineering dispute. Linus writes **Git** in days. The kernel is on Git by June. Git 1.0 in December. Maintenance passes to Junio Hamano. |
| 2005 | Google **Summer of Code**. |
| 2006 | Sun starts open-sourcing **Java**. **OpenSolaris**. Amazon EC2 makes Linux the cloud’s default guest. |
| **29 Jun 2007** | **GPLv3**. Linus keeps the kernel on GPLv2. |
| Nov 2007 | Google announces **Android**. |

Git exists because a proprietary tool failed the kernel. Firefox proves OSS can take a consumer market. The next OS war is phones.

## 2008–2014 — GitHub, phones, cloud, containers

| Date | Event |
|------|--------|
| **2008** | **GitHub** launches (April). **Android** ships (AOSP). **Chromium** (September). Stack Overflow. |
| 2009 | **Node.js**. **Go** announced. **Bitcoin**. Oracle buys Sun — Java, MySQL, and OpenSolaris crisis, which feeds **LibreOffice** and **OpenJDK** fights. |
| 2010 | **OpenStack**. **LibreOffice** (The Document Foundation forks OpenOffice after Oracle). |
| 2011 | Linux **3.0**. **systemd**. Raspberry Pi announced. Linux on ~91% of the TOP500. |
| 2012 | Raspberry Pi ships. GitHub becomes the default forge. |
| **Mar 2013** | **Docker** — containers become a product, built on kernel namespaces and cgroups. |
| **Apr 2014** | **Heartbleed** (OpenSSL). The “who maintains this?” problem goes mainstream. |
| **Jun 2014** | Google open-sources **Kubernetes**. |
| Nov 2014 | Microsoft open-sources **.NET**. Satya Nadella’s “Microsoft loves Linux” era begins. |

The social coding forge, the phone OS, and the cloud scheduler are all OSS. Linux is no longer an alternative operating system. It is the substrate.

## 2015–2019 — Cloud native, Big Tech joins, licenses crack

| Date | Event |
|------|--------|
| 2015 | **Let’s Encrypt**. **Visual Studio Code**. **TensorFlow**. **Rust 1.0**. Apple open-sources **Swift**. |
| 2016 | Microsoft **joins the Linux Foundation**. |
| 2017 | Linux hits **100% of the TOP500**. React license drama (Facebook Patents clause, later MIT). |
| **Jun 2018** | **Microsoft acquires GitHub** (~$7.5B). MongoDB **SSPL**. Commons Clause on some Redis modules. “Open core / source-available” hardens as a business model. |
| **Jul 2019** | **IBM acquires Red Hat** (~$34B) — largest OSS deal yet. GitHub Actions. |

Two tensions lock in: hyperscalers extract value from permissive licenses, and vendors start relicensing to stop them.

## 2020–2022 — Pandemic, Python 2 dies, AI weights

| Date | Event |
|------|--------|
| **1 Jan 2020** | **Python 2 end-of-life.** |
| 2020 | **WSL2** ships a real Linux kernel inside Windows. COVID accelerates remote work and Linux/dev tooling. |
| 2021 | Rust accepted for the Linux kernel as an **experiment**. GitHub **Copilot** trains on public repos — the training-data licensing fight starts. |
| **Dec 2021** | **Log4Shell**. Another “critical library, two maintainers” shock. |
| **Aug 2022** | **Stable Diffusion** — generative AI with open(ish) weights. Linux **6.0**. |
| Nov 2022 | ChatGPT (closed). The *open-weights vs open-source* argument is about to explode. |

The stack from 1992 is now the world’s production OS. The next fight is models, not kernels.

## 2023–2024 — Relicensing, forks, and a near-miss backdoor

The messiest stretch since SCO.

| Date | Event |
|------|--------|
| **21 Jun 2023** | Red Hat: public **RHEL sources only via CentOS Stream**. AlmaLinux, Rocky Linux, and Oracle Linux rebuild story breaks. |
| Jul 2023 | Meta **Llama 2** — “open” weights, not Open Source Definition–compliant. |
| **10 Aug 2023** | HashiCorp moves **Terraform** from MPL to **Business Source License**. Not OSI-open. |
| Sep 2023 | Linux Foundation **OpenTofu** fork of Terraform. |
| **Mar 2024** | Redis drops BSD for **SSPL / RSAL**. |
| **28 Mar 2024** | Linux Foundation launches **Valkey** (fork of Redis 7.2.4, BSD). AWS, Google, Oracle and others back it. |
| **29 Mar 2024** | **XZ Utils backdoor** (CVE-2024-3094) found by Andres Freund. Multi-year social-engineering of a lonely maintainer. Stopped days before Debian/Fedora stable. |
| Apr 2024 | IBM announces **$6.4B HashiCorp** acquisition. HashiCorp sends OpenTofu a cease-and-desist; no further action follows. |
| **Sep 2024** | **WordPress vs WP Engine** — trademark, wordpress.org access, plugin seizure. Open-source governance as a single-person chokepoint. |
| **Oct 2024** | OSI publishes the **Open Source AI Definition**. The field stays split. |

Twelve days in late March 2024: Redis forks, then a compression library almost backdoors SSH on a huge fraction of the internet.

## 2025–2026 — Rust is real, Linux is 35, the kernel is 7.x

| Date | Event |
|------|--------|
| **27 Feb 2025** | IBM **closes the HashiCorp acquisition**. Terraform stays BSL. OpenTofu stays MPL under Linux Foundation / CNCF. |
| 2025 | Debian 13. FreeBSD 15. Wine 10. RubyGems governance fight. **WSL open-sourced**. Linux Kernel Maintainers Summit: **Rust in Linux is no longer an experiment**. |
| **12 Apr 2026** | **Linux 7.0**. Number bump after 6.19 (Torvalds’s x.19 convention), but Rust is official; self-healing XFS; default kernel for Ubuntu 26.04 LTS. Torvalds notes AI tools are flooding the tree with corner-case bug reports. |
| **25 Aug 2026** | **35 years** since Linus’s “just a hobby, won’t be big and professional like gnu” Usenet post. |
| Late Aug 2026 | Linux **7.3-rc1** — one of the busiest merge windows on record. |
| **30 Aug 2026** | Timeline end. |

The kernel that was about 116 KB the week of 16 March 1992 is tens of millions of lines, runs phones, clouds, cars, and every TOP500 machine, and is absorbing Rust and AI-assisted review at the same time.

## The arc

```
1992  Free Unix on a 386 (Linux + 386BSD)
1998  The word "open source" + Mozilla
1999  IPOs (Red Hat, VA Linux)
2005  Git
2008  GitHub + Android + Chromium
2013  Docker
2014  Kubernetes + Heartbleed
2018  GitHub → Microsoft; source-available licenses begin
2019  IBM → Red Hat
2022  Open weights / generative AI
2023  Vendor relicensing wave (RHEL sources, Terraform BSL)
2024  Valkey + XZ backdoor + OSI AI definition
2026  Linux 7.0, Rust official, 35 years after "just a hobby"
```

---

## Four repeating plots

1. **A gap in a proprietary or unfinished system gets filled by a small group.**
   GNU Hurd → Linux. BitKeeper → Git. 386BSD stall → FreeBSD and NetBSD.
2. **A community project becomes a company, then a license fight.**
   Red Hat, Redis, HashiCorp, WordPress, MySQL/Oracle.
3. **A volunteer-maintained library becomes load-bearing infrastructure.**
   OpenSSL, log4j, xz. Heartbleed, Log4Shell, and XZ are the same story with worse special effects.
4. **The definition of “open” gets renegotiated.**
   Free software (1985) → open source (1998) → open core / SSPL / BSL (2018–) → open weights / Open Source AI (2023–).
