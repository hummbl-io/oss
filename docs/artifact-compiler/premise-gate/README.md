# Premise Gate for Artifact-Compiler Packets

## Status

- **Concept status:** candidate
- **Canon status:** not canon — `Premise Gate` is a candidate working title, namespace-audit-required
- **Issue:** #562
- **Source receipt:** YouTube video `GE6-wNk-BI8` (Andrew Hunter Murray / David Perell)
- **Related:** hummbl-io/hummbl-governance#1184

## Purpose

Artifact-compiler packets should require a compressed premise before promotion. The premise should be short, concrete, generative, and bounded by source receipts.

## Required Fields

| Field                  | Description                                     |
| ---------------------- | ----------------------------------------------- |
| `one_sentence_premise` | The compressed premise (exactly one sentence)   |
| `concrete_nouns`       | Specific objects or actors named in the premise |
| `consequence_graph`    | Second-order questions generated by the premise |
| `source_receipts`      | Receipts linking to source material             |
| `do_not_infer`         | Boundaries on what can be inferred              |
| `promotion_target`     | hold, promote, or reject                        |

## Checks

| Check                                          | Description                                 |
| ---------------------------------------------- | ------------------------------------------- |
| `premise_is_one_sentence`                      | Premise is exactly one sentence             |
| `premise_names_specific_objects_or_actors`     | Premise names concrete nouns                |
| `premise_generates_second_order_questions`     | Premise generates second-order questions    |
| `premise_does_not_overclaim_source`            | Premise does not overclaim source authority |
| `candidate_terms_marked_candidate_until_audit` | Candidate terms are marked as candidate     |

## Fixtures

| Fixture                             | Description                                                         |
| ----------------------------------- | ------------------------------------------------------------------- |
| `valid_passing_premise.json`        | Passing premise with all checks true                                |
| `invalid_vague_premise.json`        | Vague premise (no concrete nouns, no second-order questions)        |
| `rejected_overclaimed_premise.json` | Overclaimed premise (uses "proves" and "must"), rejected via checks |
