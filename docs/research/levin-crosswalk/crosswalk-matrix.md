# Crosswalk Matrix

Each row maps a Levin construct to a HUMMBL/Base120/BaseN construct with a
primary disposition, non-equivalence documentation, translation risk, and
proposed action. Dispositions follow the vocabulary in `README.md`.

**Row ID convention:** `CW-NNN` (crosswalk row number).
