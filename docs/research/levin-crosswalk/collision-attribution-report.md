# Collision and Attribution Report

## Terminology collisions

### COL-001 — "Mind" (TAME vs. HUMMBL)

- **Levin side:** TAME = "Technological Approach to **Mind** Everywhere." Mind
  is a central concept — the framework describes diverse minds.
- **HUMMBL side:** HUMMBL = "Highly Useful Mental Model Base Language." "Mental"
  refers to reasoning models, not to minds. HUMMBL does not claim agents have
  minds.
- **Collision risk:** "Mind Everywhere" (TAME) and "Mental Model" (HUMMBL) use
  related language but mean different things. External readers may conflate
  the two frameworks.
- **Recommendation:** When referencing TAME, explicitly state that HUMMBL does
  not adopt TAME's mind concept. HUMMBL uses "mental model" in the standard
  reasoning-tool sense (cf. Charlie Munger, psychology literature), not in a
  cognitive-science or phenomenal-consciousness sense.

### COL-002 — "Multi-scale" (Levin vs. HUMMBL SY15)

- **Levin side:** "Multi-scale competency architecture" — scales are biological
  (cell, tissue, organ, organism) with measurable competencies at each level.
- **HUMMBL side:** SY15 "Multi-Scale Alignment" — scales are organizational
  (strategy, operations, execution).
- **Collision risk:** "Multi-scale" appears in both but refers to different
  axes (biological vs. organizational). Using "multi-scale" without qualifier
  invites conflation.
- **Recommendation:** Always qualify: "multi-scale competency (Levin,
  biological)" vs. "multi-scale alignment (HUMMBL, organizational)."

### COL-003 — "Homeostasis" (Levin vs. HUMMBL SY8)

- **Levin side:** Anatomical homeostasis — biological target-state restoration
  via bioelectric signaling.
- **HUMMBL side:** SY8 Homeostasis/Dynamic Equilibrium — general
  systems-thinking pattern for self-regulating systems.
- **Collision risk:** Low. Both use the standard cybernetics sense of
  homeostasis (Cannon). The qualifier "anatomical" distinguishes Levin's
  usage.
- **Recommendation:** No action needed. Cite Cannon (1932) as the common
  antecedent if both are discussed together.

### COL-004 — "Persuasion" (Levin vs. general usage)

- **Levin side:** "Persuadability" — degree to which a biological system's
  behavior can be altered by non-destructive bioelectric intervention.
- **HUMMBL side:** No construct named "persuasion." Frugal Activation is the
  nearest internal construct.
- **Collision risk:** Low. The terms are different. Risk arises only if
  HUMMBL adopts "persuadability" — which this crosswalk does not recommend.
- **Recommendation:** Do not adopt "persuadability" as an HUMMBL term. If the
  concept is useful, use "intervention invasiveness" or "restoration
  routability" instead.

## Terms HUMMBL should avoid

| Term                                 | Reason                                                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| "Mind" (in TAME sense)               | HUMMBL does not make cognitive/phenomenal claims about agents.                                             |
| "Disease" (for agent misbehavior)    | Anthropomorphizes software processes. Agents have governed/ungoverned states, not healthy/diseased states. |
| "Novel beings" (for new agent types) | Implies moral status. HUMMBL governs behavior, not moral status.                                           |
| "Persuadability" (as an HUMMBL term) | Biological connotations. Use "intervention invasiveness" if the concept is needed.                         |
